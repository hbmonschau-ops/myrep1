Bank Account Manager

Benutzerhandbuch – Version 2026

1. Einführung

Der Bank Account Manager ist eine lokale Windows-Anwendung zur übersichtlichen Verwaltung Ihrer Bankkonten, Verträge und Versicherungen. Alle Daten werden verschlüsselt auf Ihrem PC gespeichert – keine Cloud, keine externen Server.

Hauptfunktionen

  • Bankkonten mit Login-Daten, Kontoständen und Notizen verwalten
  • Verträge und Versicherungen mit Laufzeiten und Zahlungsrhythmen verwalten
  • Dokumente (PDF, Word, Excel, Bilder) zu Einträgen hochladen
  • Volltextsuche in allen hochgeladenen Dokumenten
  • Mehrere Benutzerprofile (z. B. für verschiedene Personen im Haushalt)
  • Tags zum Kategorisieren und Filtern von Einträgen
  • PDF-Export von Einträgen (einzeln oder als Auswahl)
  • Verschlüsselte Speicherung aller Passwörter (AES-256)

3. Installation

3.1 Neue Installation – empfohlener Weg (Installer)

  1. PowerShell öffnen: Windows-Taste → PowerShell eingeben → Enter
  2. Ausführungsrichtlinie einmalig erlauben (einmalig, einmalig!): 
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  3. Installer herunterladen: 
    curl.exe -L "https://raw.githubusercontent.com/hbmonschau-ops/myrep1/claude/bank-account-manager-app-1Me0D/Install-BankManager.ps1" -o Install-BankManager.ps1
  4. Installer starten: 
    .\Install-BankManager.ps1
  5. Den Anweisungen folgen:
    • Installationsordner bestätigen (Standard: Desktop\BankManager)
    • Python wird automatisch installiert, falls nicht vorhanden
    • Alle benötigten Pakete werden automatisch installiert
  6. Nach Abschluss: Desktop-Verknüpfung „Bank Manager" doppelklicken
Der Installer benötigt keine Administratorrechte. Python wird nur für den aktuellen Benutzer installiert.

3.2 Manuelle Installation

mkdir C:\Users\$env:USERNAME\Desktop\BankManager
cd C:\Users\$env:USERNAME\Desktop\BankManager
curl.exe -L "https://raw.githubusercontent.com/hbmonschau-ops/myrep1/claude/bank-account-manager-app-1Me0D/bank_manager.py" -o bank_manager.pyw
pip install cryptography reportlab pdfplumber python-docx openpyxl

Danach bank_manager.pyw per Doppelklick starten.

3.3 Vorhandene Installation aktualisieren

Nur die App-Datei wird ersetzt – alle Daten bleiben erhalten:

cd C:\Users\$env:USERNAME\Desktop\BankManager
curl.exe -L "https://raw.githubusercontent.com/hbmonschau-ops/myrep1/claude/bank-account-manager-app-1Me0D/bank_manager.py" -o bank_manager.pyw

3.4 Portabler Betrieb (USB-Stick)

Legen Sie einmalig einen Ordner profiles neben die bank_manager.pyw:

mkdir C:\Users\$env:USERNAME\Desktop\BankManager\profiles

Ab sofort speichert die App alle Daten in diesem Ordner – ideal für den USB-Stick-Betrieb. Beim Update bleibt der profiles-Ordner unangetastet.

4. Erster Start & Profile

Beim allerersten Start

Es wird ein Profilname abgefragt. Der Standardname lautet „Standard". Einfach Enter drücken oder einen eigenen Namen eingeben. Das Profil wird angelegt und die App startet direkt.

Profil-Auswahl-Dialog

Bei jedem weiteren Start erscheint der Profil-Auswahl-Dialog. Hier können Sie:

  • Öffnen: Doppelklick auf ein Profil oder Schaltfläche „Öffnen"
  • Neu anlegen: Schaltfläche „Neu" → Profilname eingeben
  • Umbenennen: Profil markieren → „Umbenennen"
  • Löschen: Profil markieren → „Löschen" (nur wenn mehr als ein Profil vorhanden)
Jedes Profil hat eine vollständig getrennte Datenbank, eigene Dokumente und einen eigenen Verschlüsselungsschlüssel. Die Daten verschiedener Profile sind voneinander isoliert.

5. Benutzeroberfläche

Die Oberfläche gliedert sich in drei Bereiche:

  • Topbar (oben): Zeigt das aktive Profil und die Schaltfläche „Profil wechseln"
  • Tabs: Bankkonten • Verträge & Vers. • Suche • Einstellungen
  • Tab-Inhalt: Suchzeile oben → Datengrid (Einträge) → Dokumentenbereich unten

Das Datengrid lässt sich horizontal und vertikal scrollen, falls die Tabelle breiter als das Fenster ist.

6. Bankkonten

6.1 Konto anlegen

  1. Schaltfläche „Neu" klicken
  2. Formular ausfüllen:
    • Bankname (Pflichtfeld)
    • Kontonummer, Login-URL, Benutzername, Passwort (optional)
    • Kontostand und Stand-Datum (Format TT.MM.JJJJ)
    • Notizen
    • Tags: Tag aus Dropdown wählen → „Hinzufügen" klicken (mehrere möglich)
  3. „Speichern" klicken

6.2 Konto bearbeiten

Eintrag im Grid markieren → Schaltfläche „Bearbeiten" oder Doppelklick auf den Eintrag.

6.3 Konto löschen

Eintrag markieren → „Löschen" → Sicherheitsabfrage bestätigen.

Das Löschen eines Eintrags entfernt auch alle zugehörigen Dokumente unwiderruflich.

6.4 Suchen und Filtern

  • Suchfeld: Filtert nach Bankname, Kontonummer und Benutzername (Echtzeit)
  • Tag-Filter: Combobox neben dem Suchfeld → nur Einträge mit dem gewählten Tag werden angezeigt
  • Zurücksetzen: Suchfeld leeren oder Tag-Filter auf „(Alle)" setzen

6.5 Mehrfachauswahl und PDF-Export

  • Ctrl+Klick: Einzelne Einträge zur Auswahl hinzufügen
  • Shift+Klick: Bereich von Einträgen auswählen
  • „PDF Export": Exportiert alle markierten Einträge. Wenn nichts markiert ist, werden alle sichtbaren Einträge exportiert.

7. Verträge & Versicherungen

7.1 Vertrag anlegen

  1. Tab „Verträge & Vers." öffnen → „Neu" klicken
  2. Formular ausfüllen:
    • Bezeichnung (Pflichtfeld), Kategorie (z. B. Versicherung, Abonnement)
    • Anbieter, Vertragsnummer
    • Login-Daten (optional, verschlüsselt gespeichert)
    • Betrag und Zahlungsrhythmus (monatlich / vierteljährlich / halbjährlich / jährlich)
    • Vertragsbeginn, Vertragsende (TT.MM.JJJJ), Kündigungsfrist
    • Notizen und Tags
  3. „Speichern" klicken

Bearbeiten, Löschen, Filtern und Export funktionieren identisch wie bei Bankkonten (Abschnitt 6.2–6.5).

8. Dokumentenverwaltung

8.1 Dokument hochladen

  1. Im Tab „Bankkonten" oder „Verträge & Vers." den gewünschten Eintrag im Grid markieren
  2. Im unteren Dokumentenbereich auf „Datei hinzufügen" klicken
  3. Datei auswählen → optionale Beschreibung eingeben → OK

Die Datei wird in den Dokumentenordner des Profils kopiert. Bei unterstützten Formaten wird der Text automatisch extrahiert und für die Volltextsuche gespeichert.

8.2 Unterstützte Dateiformate

FormatDateiendungenVolltextsuche
PDF.pdfJa (benötigt pdfplumber)
Word.docxJa (benötigt python-docx)
Excel.xlsx, .xlsJa (benötigt openpyxl)
Textdateien.txt .csv .md .json .html .xmlJa
Bilder & Sonstiges.jpg .png .gif usw.Nein
PDFs, die nur eingescannte Bilder enthalten (ohne Textschicht), können nicht durchsucht werden. Nur PDFs mit eingebettetem Text werden indiziert.

8.3 Dokument öffnen

Doppelklick auf ein Dokument im Dokumentenbereich → öffnet das Dokument mit der Standard-Anwendung des Systems (z. B. Adobe Reader für PDF, Word für DOCX).

8.4 Dokument löschen

Dokument im Dokumentenbereich markieren → „Löschen" → Bestätigung. Die Datei wird aus dem Dokumentenordner entfernt.

9. Volltextsuche

9.1 Suche durchführen

  1. Tab „Suche" öffnen
  2. Suchbegriff eingeben (mindestens 2 Zeichen) → Enter
  3. Die Ergebnistabelle zeigt:
    • Dateiname – der Name der gefundenen Datei
    • Eintrag – zugehöriges Konto oder Vertrag
    • Rubrik – Bankkonten oder Verträge & Vers.
    • Beschreibung – optionale Beschreibung des Dokuments
    • Fundstelle – Textauszug mit dem gefundenen Begriff im Kontext
  4. Doppelklick auf ein Ergebnis öffnet das Dokument
Die Suche ist nicht case-sensitiv – „Rechtsschutz" findet auch „rechtsschutz" und „RECHTSSCHUTZ".

9.2 Dokumente neu indizieren

Falls die Suche keine Ergebnisse liefert, obwohl Dokumente vorhanden sind:

  • Schaltfläche „Alle neu indizieren" klicken
  • Die App extrahiert den Text aller vorhandenen Dokumente neu
  • Etwaige Fehler werden angezeigt (z. B. fehlende Bibliothek, Bild-PDF)

Die Statuszeile unten zeigt an, wie viele Dokumente noch nicht indiziert sind, wenn die Suche 0 Treffer ergibt.

10. Tags & Einstellungen

10.1 Tag anlegen

  1. Tab „Einstellungen" öffnen
  2. Schaltfläche „Neu" klicken → Tagname eingeben → OK

10.2 Tag umbenennen oder löschen

Tag in der Liste markieren → „Umbenennen" oder „Löschen".

Beim Löschen eines Tags werden alle Zuordnungen zu Konten und Verträgen automatisch entfernt.

10.3 Tag einem Eintrag zuweisen

  1. Beim Anlegen oder Bearbeiten eines Eintrags das Feld „Tags" verwenden
  2. Gewünschten Tag aus dem Dropdown-Menü wählen
  3. „Hinzufügen" klicken – der Tag erscheint als Chip mit „×"-Button
  4. Zum Entfernen: auf das „×" im Chip klicken
  5. Mehrere Tags pro Eintrag möglich

10.4 Nach Tags filtern

In den Tabs „Bankkonten" und „Verträge & Vers." gibt es neben dem Suchfeld eine Tag-Filter-Combobox. Wählen Sie einen Tag aus, um nur die Einträge mit diesem Tag anzuzeigen.

11. Benutzerprofile

11.1 Neues Profil anlegen

Im Profil-Auswahl-Dialog (erscheint beim Start): „Neu" → Profilnamen eingeben → OK.

11.2 Profil wechseln

In der laufenden App: Schaltfläche „Profil wechseln" in der Topbar klicken. Die App startet neu und zeigt den Profil-Auswahl-Dialog.

11.3 Profil umbenennen oder löschen

Im Profil-Auswahl-Dialog das Profil markieren → „Umbenennen" oder „Löschen".

Das letzte verbleibende Profil kann nicht gelöscht werden.

11.4 Datenisolierung

Jedes Profil ist vollständig isoliert:

  • Eigene Datenbank (bankaccounts.db)
  • Eigener Dokumentenordner (documents\)
  • Eigener Verschlüsselungsschlüssel (key.bin)

12. Datensicherheit & Backup

12.1 Verschlüsselung

Alle Passwörter werden mit AES-256 (Fernet) verschlüsselt gespeichert. Der Schlüssel wird beim ersten Start automatisch erzeugt und lokal gespeichert (key.bin).

12.2 Datenpfade

Standard-Modus (Daten im Windows-Benutzerprofil):

PfadInhalt
%APPDATA%\BankAccountManager\profiles.jsonProfilliste
%APPDATA%\BankAccountManager\profiles\{Name}\bankaccounts.dbDatenbank
%APPDATA%\BankAccountManager\profiles\{Name}\documents\Hochgeladene Dokumente
%APPDATA%\BankAccountManager\profiles\{Name}\key.binVerschlüsselungsschlüssel

Portabler Modus: Alle Daten liegen im Ordner der bank_manager.pyw.

12.3 Backup-Empfehlung

Sichern Sie regelmäßig den gesamten Profilordner:

%APPDATA%\BankAccountManager\profiles\{Profilname}\
Wichtig: key.bin und bankaccounts.db müssen immer zusammen gesichert werden. Ohne den passenden Schlüssel können Passwörter nicht entschlüsselt werden.
